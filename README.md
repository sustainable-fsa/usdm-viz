# usdm-viz

Animated visualizations of the [Sustainable FSA](https://sustainable-fsa.com) weekly
[US Drought Monitor archive](https://github.com/sustainable-fsa/usdm) — county-level
and CONUS-wide animations of drought conditions, January 4, 2000 – present.

- **USDM animation**: <https://sustainable-fsa.com/usdm-viz/usdm>
- **County-aggregation animation**: <https://sustainable-fsa.com/usdm-viz/usdm-counties>
